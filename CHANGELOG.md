# Clackey Changelog

All notable changes to Clackey – Typewriter Keyboard are documented in this file.

- Latest Production Version: v1.0.1 (03)

---

## [1.0.1] - 2026-10-10

### Added
- Added Voice typing feature
- Added support for 8 localized offline keyboard layouts: English (QWERTY), French (AZERTY with 10-key row 1), German (QWERTZ), Spanish (dedicated Ñ), Italian, Portuguese, Dutch, and Hindi (2-page Devanagari matrix).
- Added full 3x4 accounting numpad.
- Added 100% Offline Backup & Restore
- Added Keyboard Height Scaling Customization:
- Added 5-step keyboard height adjustment (85% to 116%) with instant live re-layout.
- Integrated Fedo feedback and support page for user-initiated feedback, bug reporting, and community roadmap voting.
- Upgraded compileSdk and targetSdk to API 36 (Android 16) ensuring compatibility with latest Google Play requirements.

---

## [1.0.0] - 2026-10-04

### Added
- Initial public release of Clackey – Typewriter Keyboard.
- Authentic typewriter acoustic engine with SoundPool round-robin mechanical clack audio and carriage return bell.
- Bead-blasted aluminum plate UI (`MechanicalPlateLayout`) with 3D circular typewriter keycaps and haptic vibration.
- Built-in GIPHY GIF search and offline personal dictionary.
- Private clipboard manager with 30s, 1m, and 5m auto-clear timeouts.
- Core settings: Preferences, Themes, Sound Profiles, and Help & Support.
